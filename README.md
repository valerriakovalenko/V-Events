# V EVENTS — website

Багатосторінковий адаптивний сайт івент-агенції V EVENTS. Створений на чистих HTML, CSS та JavaScript без фреймворків.

## Структура
- `index.html` — головна сторінка
- `about.html` — про агенцію
- `services.html` — послуги
- `portfolio.html` — фотогалерея з переглядом фото
- `contacts.html` — контакти та форма заявки
- `assets/style.css` — стилі та адаптивність
- `assets/script.js` — перемикач мов, мобільне меню, анімації та форма

## Перегляд локально
Відкрийте `index.html` у браузері. Для зручнішого тестування можна використати розширення Live Server у Visual Studio Code.

## Публікація на GitHub Pages
1. Створіть новий репозиторій на GitHub.
2. Завантажте всі файли та папку `assets` у корінь репозиторію.
3. Відкрийте **Settings → Pages**.
4. У розділі **Build and deployment** оберіть **Deploy from a branch**.
5. Оберіть гілку `main` і папку `/ (root)`, натисніть **Save**.
6. Через деякий час GitHub Pages надасть адресу опублікованого сайту.
